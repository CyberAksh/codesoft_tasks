# Beginner Web Projects

This repository contains three beginner-friendly web projects built entirely with HTML, CSS, and vanilla JavaScript. There are no frameworks or build steps required.

## Projects Overview

| Task | Project Name | Description | Technologies |
|------|--------------|-------------|--------------|
| **1** | [Personal Portfolio](./task1-portfolio/index.html) | A responsive personal portfolio website showcasing skills and projects, featuring dark mode and contact form validation. | HTML5, CSS3, JS |
| **2** | [Landing Page](./task2-landing-page/index.html) | A modern landing page for a fictional fitness app "Stride", complete with a CSS phone mockup, pricing tables, and responsive grid. | HTML5, CSS3, JS |
| **3** | [Calculator](./task3-calculator/index.html) | A functional web calculator with a sleek glassmorphism UI, keyboard support, and edge-case handling. | HTML5, CSS3, JS |

## Features

- **Semantic HTML5:** Clean, accessible, and structured code.
- **Modern CSS:** Fully responsive using Flexbox and CSS Grid. Includes hover effects, transitions, and modern design aesthetics (gradients, glassmorphism).
- **Vanilla JavaScript:** DOM manipulation, event handling, simple form validation, dark mode persistence (localStorage), and math logic.
- **Accessibility:** Alt text, proper contrast, and keyboard navigation support.

## How to Run

1. Clone or download this repository.
2. Navigate to the specific project folder (`task1-portfolio`, `task2-landing-page`, or `task3-calculator`).
3. Double-click the `index.html` file to open it directly in your web browser. No local server is required.
